# 参照:WenfuRainbow/heybox 原始 README(用户提供,2026)

> 小黑盒论坛 VSCode 插件。在 VSCode 中浏览小黑盒(xiaoheihe.cn)论坛帖子和评论,支持隐身模式。

## 功能清单(移植到 DSH Web 的映射)

| 原功能 | 说明 | DSH 版映射 |
|---|---|---|
| 登录/退出登录 | 粘贴浏览器 Cookie 登录;heyboxId 从 Cookie 提取;deviceId 自动生成 | 面板内登录弹窗 → Cookie 只存主机侧 |
| 主题切换 | 跟随 VSCode / 暗色 / 亮色 | 跟随 DSH 主题(auto)+ 强制暗/亮 |
| Tab:推荐 | 热门推荐信息流 | 分区顶部 Tab「推荐」 |
| Tab:板块 | 数码硬件、盒友杂谈、Steam…;点板块展开帖子列表;加载更多分页 | Tab「板块」 |
| Tab:收藏 | 我的收藏帖子;本地 + 服务端同步 | Tab「收藏」(本地 + API 同步) |
| 搜索帖子 | 全站搜索,分页,返回话题列表 | 面板内搜索 |
| 帖子详情 | 正文 + 评论(图片/楼层/子评论嵌套),自动加载去重分页;折叠提示 | 详情视图 |
| 图片大小控制 | 5%~100% 拖动条,localStorage 持久化,滚动时固定 | 详情页顶部滑块 |
| 图片悬停预览 | 悬停看原图大小预览 | 简化:点击看原图 |
| 消息通知 | 登录后每 3 分钟查回复/点赞,可跳转、标记已读 | 铃铛徽标 + 列表(轮询) |
| 隐身/简约模式 | VSCode 场景用 | 不做(DSH 非代码编辑器) |

## 数据来源
- 插件仅通过 API 读取公开论坛数据;Cookie 用于收藏/消息等账号功能。
- Cookie 会过期,过期需重新粘贴。

## 隐私
- 仅读公开数据;Cookie 加密存储(原版 VSCode SecretStorage)。
- 免责:非官方开源项目,仅供学习交流,版权归小黑盒所有。
